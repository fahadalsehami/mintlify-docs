Medera Medical Coding generates accurate, defensible codes from clinical context — each code anchored to a quoted note span and reported with calibrated confidence. The same API powers in-encounter code suggestions during scribing, post-visit revenue-cycle sweeps, and real-time PA detection during intake.

<Tip>
  Every code returned by the Medera API includes the documentation span that supports it. Suggestions never auto-post — the coder or clinician confirms.
</Tip>

## What you get back

Every code in the Medera response includes:

```json
{
  "system": "icd-10-cm",
  "code": "F32.1",
  "display": "Major depressive disorder, single episode, moderate",
  "confidence": 0.92,
  "anchor": {
    "documentId": "doc_abc",
    "span": { "start": 412, "end": 489 },
    "quote": "Patient reports persistent low mood for 6 weeks..."
  },
  "severity_qualifier_suggestions": ["moderate", "severe"],
  "documentation_gap": null
}
```

| Field | Description |
| :--- | :--- |
| `system` | Coding system (e.g. `icd-10-cm`, `cpt`) |
| `code` | The code that best describes the entity |
| `display` | Human-readable description |
| `confidence` | 0–1, calibrated against documentation strength |
| `anchor` | Document span and quote supporting the code |
| `severity_qualifier_suggestions` | Optional specificity upgrades |
| `documentation_gap` | What additional documentation would strengthen the code |
