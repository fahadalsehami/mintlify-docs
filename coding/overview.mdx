## Capabilities

- **Encounter coding** — generate codes for a signed (or in-progress) note
- **CDI review** — surface documentation gaps before sign-off
- **Revenue cycle sweeps** — retrospective audits and missed-code surfacing
- **Coder workflow** — code suggestions with documented support
