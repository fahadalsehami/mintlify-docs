---
title: "CDI"
description: "Concurrent and retrospective documentation review"
---


Run CDI review via the [CDI Agent](/agentic/agents/clinical-documentation-improvement). The agent surfaces specificity, severity, and completeness gaps as clinical queries — not as auto-applied code changes — and logs the clinician's accept / reject decision.

Behind the scenes, CDI uses the same code suggestion endpoints (`/api/therapy/suggest-codes` + `/api/therapy/validate-note`) but interprets the gap rather than the code.
