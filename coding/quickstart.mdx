---
title: "Coding Quickstart"
description: "Suggest codes for a signed note"
---


```bash
curl -X POST https://api.medera.ai/api/therapy/suggest-codes \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "diagnosis_text": "Major depressive disorder, recurrent, moderate",
    "procedure_text": "45-minute individual psychotherapy",
    "context": { "patient_id": "pat_abc" }
  }'
```

Response:

```json
{
  "suggested_codes": [
    {
      "code": "F33.1",
      "system": "icd-10-cm",
      "description": "Major depressive disorder, recurrent, moderate",
      "confidence": 0.92
    },
    {
      "code": "90834",
      "system": "cpt",
      "description": "Psychotherapy, 45 minutes",
      "confidence": 0.95
    }
  ]
}
```
