## `GET /api/intake-calls/{id}`

Get an intake call with state, screener results, ICD-10 candidates, and the handoff packet.

### Example

```bash
curl -X GET https://api.medera.ai/api/intake-calls/{id} \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
