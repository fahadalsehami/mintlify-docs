## `POST /api/co-therapy-sessions`

Create a multi-provider co-therapy session.

### Example

```bash
curl -X POST https://api.medera.ai/api/co-therapy-sessions \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
