## `POST /api/appointments`

Schedule an appointment with calendar integration and ICS / RRULE support.

### Example

```bash
curl -X POST https://api.medera.ai/api/appointments \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
