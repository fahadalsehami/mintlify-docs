## `POST /api/clinical/notes`

Create a clinical note (typically generated via Visit Scribe).

### Example

```bash
curl -X POST https://api.medera.ai/api/clinical/notes \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
