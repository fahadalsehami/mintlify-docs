## `GET /api/audit/integrity-checkpoints`

Get Merkle tree checkpoints for the audit log. Use to verify tamper-evident integrity.

### Example

```bash
curl -X GET https://api.medera.ai/api/audit/integrity-checkpoints \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
