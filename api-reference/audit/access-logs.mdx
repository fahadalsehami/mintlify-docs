## `GET /api/audit/access-logs`

List PHI access events with actor, resource, action, and outcome.

### Example

```bash
curl -X GET https://api.medera.ai/api/audit/access-logs \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
