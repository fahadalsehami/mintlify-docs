## `GET /api/patients`

List patients in the tenant. Cursor-paginated, filterable by name, DOB, provider, and program.

### Example

```bash
curl -X GET https://api.medera.ai/api/patients \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
