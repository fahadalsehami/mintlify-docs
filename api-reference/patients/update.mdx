## `PATCH /api/patients/{id}`

Update specific fields. Only fields in the body are updated. PHI changes generate a separate audit event.

### Example

```bash
curl -X PATCH https://api.medera.ai/api/patients/{id} \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
