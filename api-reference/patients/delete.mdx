## `DELETE /api/patients/{id}`

Soft-delete a patient. PHI is tombstoned but retained in the audit log per HIPAA 6-year retention.

### Example

```bash
curl -X DELETE https://api.medera.ai/api/patients/{id} \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
