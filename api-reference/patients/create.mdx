## `POST /api/patients`

Create a new patient. The PHI fields are encrypted at rest with AES-256-GCM. Phone and email are stored both encrypted and hashed (for search).

**Mount stack:** `resolveDeploymentScope, authenticateToken, setTenantContext, sessionTimeoutMiddleware, phiAuditMiddleware, consentGate, purposeBasedAccess('patients', 'TREATMENT', 'PAYMENT', 'OPERATIONS', 'EMERGENCY')`

### Request body

```json
{
  "first_name": "...",
  "last_name": "...",
  "dob": "1985-04-12",
  "ssn": "...",
  "insurance": { ... },
  "address": { ... },
  "phone": "...",
  "email": "..."
}
```

### Response

```json
{ "id": "pat_abc", "created_at": "..." }
```
