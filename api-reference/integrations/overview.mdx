Medera connects to the following EHRs and clinical infrastructure: | EHR / System | Integration |
| :--- | :--- |
| Epic | FHIR R4 + SMART-on-FHIR |
| Cerner (Oracle Health) | FHIR R4 |
| athenahealth | FHIR R4 + HL7 v2.x ADT |
| Allscripts | FHIR R4 |
| eClinicalWorks | FHIR R4 |
| NextGen | FHIR R4 |
| SimplePractice | API |
| e-Rx network | E-prescribing |
| billing clearinghouse | Billing / RCM | Connections are managed in the Console under **Integrations**.
