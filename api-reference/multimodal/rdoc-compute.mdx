---
title: "RDoC compute (internal)"
description: "RDoC profile computation"
---


RDoC computation is internal to `MultimodalTherapyAnalyzer.analyze_session_with_multimodal()` and is not exposed as a standalone endpoint. To trigger RDoC computation, use:

```
POST /api/multimodal-therapy/analyze-session
```

The response includes `rdoc.constructs[]` with one entry per construct.
