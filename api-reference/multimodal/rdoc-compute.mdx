## `POST /api/multimodal/rdoc/compute`

Compute RDoC construct activations from multimodal features.

### Example

```bash
curl -X POST https://api.medera.ai/api/multimodal/rdoc/compute \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
