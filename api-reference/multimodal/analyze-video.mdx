## `POST /api/multimodal/analyze-video`

Analyze uploaded video for HR, BP, HRV, RR, stress, and affect.

### Request body

```json
multipart/form-data: video=@session.mp4
```

### Example

```bash
curl -X POST https://api.medera.ai/api/multimodal/analyze-video \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
