The Medera API is a REST + WebSocket API for behavioral and mental health applications. Every endpoint is HIPAA-grade, scoped to a tenant, and protected by Row-Level Security.

## Base URLs

| Environment | Base URL |
| :--- | :--- |
| Production | `https://api.medera.ai` |
| Staging | `https://staging.api.medera.ai` |
| Sandbox | `https://sandbox.api.medera.ai` |

## Authentication

Every request requires an `Authorization: Bearer <token>` header. See [Authentication Overview](/authentication/overview).

## Content type

Request and response bodies are JSON. File uploads use `multipart/form-data`.

## Versioning

The API is versioned via the URL path (`/api/v1/...` is implicit; `/api/v2/...` is explicit). See [Versioning](/api-reference/versioning).

## Rate limits

Per-tenant default: 1000 requests per minute, burst 100. See [Rate Limits](/api-reference/rate-limits).
