## `GET /api/agent-workflows/executions/{id}`

Get a workflow execution trace.

### Example

```bash
curl -X GET https://api.medera.ai/api/agent-workflows/executions/{id} \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
