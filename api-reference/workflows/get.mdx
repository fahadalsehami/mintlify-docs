## `GET /api/agent-workflows/{id}`

Get a workflow definition with nodes, connections, and variables.

### Example

```bash
curl -X GET https://api.medera.ai/api/agent-workflows/{id} \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
