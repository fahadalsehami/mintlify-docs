## `POST /oauth/token`

Exchange client credentials for an access token.

### Request body

```json
{
  "grant_type": "client_credentials",
  "client_id": "...",
  "client_secret": "...",
  "audience": "api.medera.ai",
  "scope": "patients:read sessions:write"
}
```

### Response

```json
{
  "access_token": "eyJhbGciOi...",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "patients:read sessions:write"
}
```

### Example

```bash
curl -X POST https://api.medera.ai/oauth/token \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
