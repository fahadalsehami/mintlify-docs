---
title: "Clerk webhook receiver"
description: "Receive Clerk lifecycle events"
---


```
POST /api/clerk-webhooks
```

Receives Clerk lifecycle webhooks: `user.created`, `user.updated`, `user.deleted`, `organization.created`, `organization.updated`, `organizationMembership.created`, `organizationMembership.deleted`.

Signature: validated via [Svix](https://svix.com) HMAC headers (`svix-id`, `svix-timestamp`, `svix-signature`).

`clerkUserSyncService.js` handles the reflection into the `users` and `organization_memberships` tables.
