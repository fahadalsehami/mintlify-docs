## `POST /api/auth/forgot-password`

Trigger a password reset email via Clerk. Rate-limited to 10 requests / 15 minutes per IP.

### Example

```bash
curl -X POST https://api.medera.ai/api/auth/forgot-password \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
