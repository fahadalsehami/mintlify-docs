## `POST /api/pa/{id}/appeal`

Generate an appeal for a denied PA.

### Example

```bash
curl -X POST https://api.medera.ai/api/pa/{id}/appeal \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json"
```
