---
title: "Core Concepts"
description: "The fundamental building blocks of the Agentic Framework"
---


| Concept | Description |
| :--- | :--- |
| **Agent** | A task-specific actor with a typed configuration and a documented execution flow |
| **Expert** | A typed capability (e.g. PHQ-9 administration, ICD-10 coding) that agents bundle |
| **Orchestrator** | Top-level coordinator that routes messages, manages context, and enforces policy |
| **Context** | A thread of messages, memories, and tasks scoped to a patient or workflow |
| **Task** | A unit of agent work with status, artifacts, and history |
| **Message** | Input or output bound to a context |
| **Memory** | Persistent state available to the agent across contexts (scoped) |
| **Workflow** | A composed graph of agents, experts, and logic nodes built on the Canvas |
