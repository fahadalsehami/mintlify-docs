Surface peer-reviewed evidence — anchored, cited, and bounded.

## Configuration

| Field | Description |
| :--- | :--- |
| `library` | Approved evidence library (PubMed, UpToDate, internal) |
| `citation_requirements` | Citation requirements |
| `currency_thresholds` | Currency thresholds |
| `surfacing_policy` | Surfacing policy |

## Execution

1. Receives a clinical question with patient context
2. Searches the approved evidence library
3. Synthesizes the evidence with explicit citations
4. Reports currency and bounds the answer to documented sources
5. Logs the query and the response for audit

## Composable experts

| Expert | Role |
| :--- | :--- |
| **PubMed Expert** | Peer-reviewed literature search |
| **UpToDate Expert** | Clinical reference search |
| **Evidence Synthesis Expert** | Synthesis with bounded conclusions |
| **Citation Expert** | Citation rendering + currency |

## Compliance guarantees

<Warning>

- Every claim carries an explicit citation

- Currency of evidence is reported

- Conclusions are bounded to documented sources
</Warning>

## Endpoints

AI

Services: `AdvancedClinicalRAG.hybrid_search` → `CitedResponse`.
