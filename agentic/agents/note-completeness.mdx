Pre-sign-off completeness against practice template + quality programs (HEDIS, MIPS).

## Configuration

| Field | Description |
| :--- | :--- |
| `template_id` | Practice template + required-element list |
| `programs` | Quality program element set (HEDIS, MIPS, …) |
| `enforcement` | Blocking vs. advisory sign-off policy |
| `pre_signoff_timing` | Pre-sign-off review timing |

## Execution

1. Reads the note against the practice template
2. Flags missing required elements per template and per program
3. Surfaces the gap with the template's expected language
4. Logs the pre-sign-off completeness state
5. Optionally blocks sign-off until critical fields are filled

## Composable experts

| Expert | Role |
| :--- | :--- |
| **Template Adherence Expert** | Practice template completeness |
| **Quality Program Expert** | HEDIS, MIPS, program-specific elements |
| **Audit Trail Expert** | Pre-sign-off state logged |
| **Sign-off Workflow Expert** | Blocking vs. advisory enforcement |

## Compliance guarantees

<Warning>
- Completeness checks are deterministic and template-driven
- Blocking enforcement is explicit and configured by the practice
- Pre-sign-off state is logged for every encounter
</Warning>

## Endpoints

REST: `POST /api/therapy/validate-note`.
