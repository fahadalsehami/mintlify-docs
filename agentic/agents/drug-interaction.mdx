</Info> Catch interactions that matter in psychopharmacology and primary care overlap. ## Configuration | Field | Description |
| :--- | :--- |
| `library` | Drug interaction library (DrugBank, RxNorm) |
| `severity_threshold` | Severity threshold for surfacing |
| `specialty_context` | Specialty context (psychopharm, primary care) |
| `policy` | Allergy + contraindication policy | ## Execution 1. Reads the active med list and pending order
2. Runs interaction and contraindication checks
3. Surfaces severity-graded warnings with rationale
4. Logs the check and the prescribing decision
5. Tracks warning override patterns ## Composable experts | Expert | Role |
| :--- | :--- |
| **DrugBank Expert** | Interaction library queries |
| **Psychopharm Interaction Expert** | BH-specific interaction logic |
| **Contraindication Expert** | Patient comorbidity + allergy logic |
| **Severity Grading Expert** | Clinical severity scoring | ## Compliance guarantees <Warning>
- Interaction library is current and configurable
- Severity grading is explicit
- Overrides are logged with rationale
