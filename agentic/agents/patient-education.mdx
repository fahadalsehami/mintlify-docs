<Info>
  **Category:** Patient-Facing &nbsp;·&nbsp; **Signals:** Clinical content · Patient reading level · Preferred language · Active diagnoses
</Info>

Translate clinical content into the patient's language, reading level, and context — drawn from a clinician-approved library.

## Configuration

| Field | Description |
| :--- | :--- |
| `library_id` | Practice education library + approved content |
| `reading_level` | Patient reading-level constraints |
| `languages` | Translation language set |
| `channel` | Channel + delivery policy |

## Execution

1. Loads the clinical content the clinician wants delivered
2. Adapts it to the patient's reading level and preferred language
3. Tailors it to the active diagnoses and medications
4. Delivers via the configured channel
5. Tracks engagement and comprehension

## Composable experts

| Expert | Role |
| :--- | :--- |
| **Plain-Language Expert** | Reading-level + clarity |
| **Translation Expert** | Multilingual fidelity |
| **Tailoring Expert** | Active diagnoses + medications |
| **Engagement Expert** | Channel selection + delivery |

## Compliance guarantees

<Warning>
- Education content is drawn from a clinician-approved library
- Reading level and translation are explicit and configurable
- Engagement and comprehension are tracked, not assumed
</Warning>

## Endpoints

Canvas: `transform` + `escalate` nodes for delivery; backend `POST /api/communications`.
