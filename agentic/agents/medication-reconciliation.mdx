Maintain a clean, auditable medication list across every transition.

## Configuration

| Field | Description |
| :--- | :--- |
| `sources` | Connected med list sources (EHR, e-Rx network, pharmacy) |
| `cadence` | Practice reconciliation cadence |
| `escalation_tree` | Discrepancy escalation tree |
| `documentation` | Documentation requirements |

## Execution

1. Pulls med lists from connected sources
2. Reconciles across sources and patient-reported list
3. Surfaces discrepancies with rationale
4. Documents the reconciliation and the resolution
5. Tracks the active list as the source of truth

## Composable experts

| Expert | Role |
| :--- | :--- |
| **Med List Source Expert** | EHR, e-Rx network, pharmacy integration |
| **Reconciliation Expert** | Discrepancy logic + resolution |
| **Patient Report Expert** | Patient-reported list capture |
| **Documentation Expert** | Reconciliation logging |

## Compliance guarantees

<Warning>

- Reconciliation runs at every transition by default

- Discrepancies are surfaced with rationale

- The active list is documented and auditable
</Warning>

Canvas: `rails/pharmacy` + `ehr-sync` (MedicationRequest).
