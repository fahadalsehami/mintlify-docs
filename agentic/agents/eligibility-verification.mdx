Verify benefits and surface coverage gaps before the visit.

## Configuration

| Field | Description |
| :--- | :--- |
| `endpoints` | Connected payer eligibility endpoints |
| `service_codes` | Service code set per visit type |
| `communication` | Patient communication policy |
| `escalation_tree` | Coverage-gap escalation tree |

## Execution

1. Pulls patient demographics and insurance from the chart
2. Queries the payer eligibility API
3. Identifies covered services, copays, and gaps
4. Surfaces coverage gaps before the visit
5. Documents the verification result in the chart

## Composable experts

| Expert | Role |
| :--- | :--- |
| **Eligibility API Expert** | Payer endpoint integration + retry |
| **Coverage Gap Expert** | Service code coverage analysis |
| **Copay Calculator Expert** | Patient cost estimation |
| **Documentation Expert** | Eligibility result logging |

## Compliance guarantees

<Warning>

- Verification is real-time, not cached past policy expiration

- Coverage gaps surface before the visit

- Patient cost estimates are sourced from eligibility, not estimates
</Warning>

## Endpoints

Canvas: `fhir-query` (Coverage) + `ehr-sync`.
