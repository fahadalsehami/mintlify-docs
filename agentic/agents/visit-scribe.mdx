Listen, write, code, and post the note before the patient leaves the room — every claim and code anchored to a transcript span.

## Configuration

| Field | Description |
| :--- | :--- |
| `template_id` | Practice SOAP template and required fields |
| `ehr_target` | Epic, Cerner, athenahealth, eClinicalWorks, NextGen, … |
| `code_scope` | Code-set scope and revenue-cycle rules |
| `signoff_workflow` | Sign-off and clinician edit windows |

## Execution

1. Captures encounter audio with speaker diarization
2. Drafts the SOAP note in the practice template during the encounter
3. Suggests ICD-10 and CPT codes anchored to quoted documentation
4. Posts the note and code set to the EHR through the integration adapter
5. Logs every claim with the transcript span that supports it

## Composable experts

| Expert | Role |
| :--- | :--- |
| **ICD-10 Coding Expert** | Diagnosis coding with documented support |
| **CPT / E&M Expert** | Procedure and E&M coding |
| **SOAP Structure Expert** | Practice template adherence + completeness |
| **Clinical Terminology Expert** | Normalization across SNOMED, LOINC, RxNorm |

## Compliance guarantees

<Warning>
- Every code is anchored to a quoted span supporting it
- Clinician sign-off is required; agent edits are surfaced as suggestions
- Notes are written to the EHR only after the clinician signs
</Warning>

## Endpoints

REST: `POST /api/clinical/start` · `/api/clinical/chunk` · `/api/clinical/stop` · `POST /api/therapy/generate-soap-note-enhanced` · `POST /api/therapy/notes/{id}/finalize`.
