## Overview

The Clinical Guidelines Agent runs against an active guideline library — APA, NICE, USPSTF, and specialty programs — surfacing care-step gaps to the clinician with citations.

Every check is documented for audit and adherence is tracked over time.

## How this agent works

### Configuration

This agent takes the following configuration from your practice settings:

- Active guideline library
- Specialty scope
- Surfacing policy (advisory vs. blocking)
- Documentation requirements

### Execution

At runtime, the agent executes the following steps:

1. Reads the chart against the active guideline library
2. Identifies care steps required by guidelines
3. Surfaces gaps to the clinician with citations
4. Documents the guideline check for audit
5. Tracks guideline adherence over time

## Composable experts

The Clinical Guidelines Agent bundles the following experts from the [registry](/agentic/experts/overview):

| Expert | Role |
| :--- | :--- |
| **APA Guideline Expert** | American Psychiatric Association guidance |
| **NICE Guideline Expert** | UK NICE guidance |
| **USPSTF Guideline Expert** | US Preventive Services Task Force |
| **Program Guideline Expert** | Specialty program guidance |

## Typical use cases

- Surface guideline gaps to the clinician with citations
- Track guideline adherence over time
- Document the guideline check for audit
- Update the guideline library as new guidance is published

## Compliance & safety guarantees

- Guideline citations are explicit and current
- Gaps are surfaced as suggestions, not auto-applied
- Adherence is tracked longitudinally
