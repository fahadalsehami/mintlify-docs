Stratify a population for proactive outreach with documented rationale.

## Configuration

| Field | Description |
| :--- | :--- |
| `risk_model` | Risk model definition + weights |
| `thresholds` | Stratification thresholds |
| `prioritization` | Outreach prioritization rules |
| `documentation` | Documentation requirements |

## Execution

1. Reads the population against the risk model
2. Stratifies patients by documented rationale
3. Surfaces outreach priorities to the care team
4. Documents the stratification for audit
5. Tracks risk changes over time

## Composable experts

| Expert | Role |
| :--- | :--- |
| **Risk Model Expert** | Definition + weight management |
| **Stratification Expert** | Threshold logic + band assignment |
| **Outreach Prioritization Expert** | Capacity + prioritization logic |
| **Documentation Expert** | Stratification logging |

## Compliance guarantees

<Warning>
- Risk model definition is explicit and configurable
- Stratification rationale is documented
- Outreach prioritization respects capacity
</Warning>
