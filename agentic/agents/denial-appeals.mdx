Appeal denials with documented evidence and payer-policy citations.

## Configuration

| Field | Description |
| :--- | :--- |
| `payer_library` | Payer policy library + carrier rules |
| `approval_workflow` | Practice approval workflow |
| `evidence_base` | Evidence base (PubMed, internal protocols) |
| `templates` | Appeal letter templates |

## Execution

1. Reads the denial reason and the original claim
2. Pulls relevant chart context and payer policy
3. Drafts the appeal letter with documented evidence
4. Routes for clinician approval
5. Tracks appeal status and outcome

## Composable experts

| Expert | Role |
| :--- | :--- |
| **Payer Policy Expert** | Carrier-specific appeal criteria |
| **PubMed Expert** | Peer-reviewed evidence |
| **Chart Evidence Expert** | Relevant chart spans |
| **Appeal Strategy Expert** | Appeal letter structure + arguments |

## Compliance guarantees

<Warning>
- Every appeal carries chart and policy citations
- Appeal recommendations include new evidence, not the same argument
- Submission requires explicit clinician approval
</Warning>

## Endpoints

REST: `POST /api/prior-auth/requests/{id}/appeal`.
