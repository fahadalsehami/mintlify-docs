Keep the patient, the chart, and the next step in lockstep across every transition. Voice agent Alex on ElevenLabs `pNInz6obpgDQGcFmaJgB` (Adam).

## Configuration

| Field | Description |
| :--- | :--- |
| `care_plan_templates` | Practice care-plan templates by program |
| `referral_graph` | In-network and partner referral graph |
| `outreach_channels` | Outreach channels + compliance caps (SMS, email, phone) |
| `closed_loop_requirements` | Closed-loop documentation requirements |

## Execution

1. Maintains the care plan as the source of truth across transitions
2. Triggers outreach for next-step appointments and screener refreshes
3. Generates referrals and tracks closed-loop confirmation
4. Surfaces handoff risk to the care team with rationale
5. Documents every coordination action in the chart

## Composable experts

| Expert | Role |
| :--- | :--- |
| **Care Plan Expert** | Practice template adherence + milestone reasoning |
| **Referral Graph Expert** | Network logic + partner-preference rules |
| **Outreach Expert** | Channel selection + timing within compliance caps |
| **Closed-Loop Audit Expert** | Receipt, scheduling, completion, documentation |

## Compliance guarantees

<Warning>
- Outreach is always within practice-configured compliance caps
- Referrals are tracked to closed-loop confirmation or escalation
- Care plan milestones are tracked against a documented template
</Warning>

## Endpoints

REST: `/api/care-orchestrator/workflows` · `/api/care-orchestrator/voice/calls` for Alex outbound calls.
