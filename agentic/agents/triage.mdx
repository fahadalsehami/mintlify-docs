Stratify acuity and route patients with the rigor of an ED triage nurse — ESI levels, C-SSRS risk band, documented routing.

## Configuration

| Field | Description |
| :--- | :--- |
| `routing_matrix` | Practice routing matrix by ESI level and service line |
| `screeners` | Approved screener set and cut-points |
| `escalation_tree_id` | Crisis handoff destinations + on-call tree |
| `acuity_thresholds` | Telehealth vs. in-person vs. ED referral |

## Execution

1. Ingests intake summary, chart history, and any active screener results
2. Runs C-SSRS and PHQ-9 risk logic against documented criteria
3. Applies the ESI 5-level framework adapted for behavioral health
4. Issues a routing recommendation with rationale and confidence
5. Hands off to clinician or escalates per the practice routing matrix

## Composable experts

| Expert | Role |
| :--- | :--- |
| **C-SSRS Risk Expert** | Suicide-risk classification with rationale |
| **ESI Acuity Expert** | 5-level acuity stratification for BH |
| **Vocal Prosody Expert** | Distress + urgency markers from voice |
| **Risk Prior Expert** | Historical risk factors from chart |

## Compliance guarantees

<Warning>

- ESI level and C-SSRS risk band are documented for every routing decision

- Crisis-language triggers immediate human-on-call handoff, no agent gating

- Routing rules are configured by the practice, not inferred by the model
</Warning>

## Endpoints

Triage runs inside Canvas workflows via the `triage-agent` node type and the `rails/triage` rail.

Standalone REST: `POST /api/clinical/triage`.
