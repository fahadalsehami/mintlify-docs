Assemble quality-program submissions from the chart, not a spreadsheet.

## Configuration

| Field | Description |
| :--- | :--- |
| `programs` | Active quality programs (HEDIS, MIPS, …) |
| `reporting_period` | Reporting period + submission cadence |
| `thresholds` | Data completeness thresholds |
| `destinations` | Reporting destinations |

## Execution

1. Reads the chart for the program measure set
2. Identifies data gaps that block measure completion
3. Surfaces gaps to the care team for remediation
4. Assembles the submission once complete
5. Submits to the program destination

## Composable experts

| Expert | Role |
| :--- | :--- |
| **HEDIS Measure Expert** | HEDIS measure set + logic |
| **MIPS Measure Expert** | MIPS measure set + scoring |
| **Data Completeness Expert** | Gap analysis + remediation |
| **Submission Expert** | Program submission formats |

## Compliance guarantees

<Warning>

- Submissions are assembled from the chart, not a separate workflow

- Gaps surface to the care team for remediation

- Every submission is documented for audit
</Warning>
