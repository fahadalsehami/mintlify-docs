The Agentic Framework is exposed via the [JavaScript SDK](/sdks/js/overview) and [Python SDK](/sdks/python/overview). Tenants can additionally configure integrations under **Console → Integrations**:

| Integration | Type |
| :--- | :--- |
| Epic | FHIR R4 + SMART-on-FHIR |
| Cerner (Oracle Health) | FHIR R4 |
| athenahealth | FHIR R4 + HL7 v2.x ADT |
| Allscripts | FHIR R4 |
| eClinicalWorks | FHIR R4 |
| NextGen | FHIR R4 |
| Surescripts | E-prescribing |
| Waystar | Billing / RCM |
| Twilio | Voice / SMS |
| Vapi | Voice orchestration |
| MCP servers | Custom tools |
