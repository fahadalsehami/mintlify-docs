## Workflow state machine

The state machine in `src/care_orchestrator/workflow/state_machine.py` defines 30+ states across Referral (18 states), Prescription (14 states), Lab (15 states), and Care Plan (10 states), plus generic states: `DRAFT`, `INITIATED`, `PENDING`, `IN_PROGRESS`, `WAITING`, `COMPLETED`, `FAILED`, `CANCELLED`, `EXPIRED`.

Transitions carry `from_state`, `to_state`, `event`, optional `guard` function, optional `action` function, `timeout`, `escalation_state`, and `priority`.
