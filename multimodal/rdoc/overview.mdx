The RDoC Construct Computer maps multimodal features to **15 RDoC constructs across 5 domains** with zero overlap. Output is `ConstructActivation` objects with score (0–1), confidence, feature contributions, and clinical interpretations.

```json
{
  "construct": "potential_threat_anxiety",
  "domain": "negative_valence",
  "score": 0.74,
  "confidence": "HIGH",
  "feature_contributions": {
    "f0_mean": 0.31,
    "jitter": 0.22,
    "speaking_rate": 0.18,
    "facial_affect_fear": 0.14,
    "linguistic_uncertainty": 0.15
  },
  "clinical_interpretation": "Elevated anxiety markers...",
  "window": { "start_ms": 0, "end_ms": 30000 }
}
```

## Confidence calibration

Confidence is reported as `VERY_HIGH`, `HIGH`, `MODERATE`, `LOW`, `VERY_LOW`. Below `MODERATE`, the activation is delivered with `requires_human_review: true`.

## Latency

Construct activation latency: < 110 ms P95 per window.
