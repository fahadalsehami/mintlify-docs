---
title: "Negative Valence Systems"
description: "Acute Threat, Potential Threat, Sustained Threat"
---


| Construct | Description |
| :--- | :--- |
| Acute Threat (Fear) | Immediate, identifiable threat response |
| Potential Threat (Anxiety) | Anticipatory response to uncertain threat |
| Sustained Threat | Prolonged response to chronic stressor |
