---


The Facial Physiological Engine extracts physiological signal from video using MediaPipe 468-point landmarks plus rPPG (remote photoplethysmography) techniques.

## Outputs

| Signal | Notes | Requirements |
| :--- | :--- | :--- |
| Heart Rate (HR) | <5 bpm MAE | Min 30 s, SNR > 3.0 |
| Blood Pressure | Systolic / diastolic with confidence | Min 60 s |
| HRV (SDNN, RMSSD, LF/HF, SD1, SD2) | Standard HRV metrics | Min 60 s |
| Respiration Rate | Per-minute | Min 30 s |
| Stress Index | 0–100 with PNS/SNS balance | Min 60 s |
| Affect | 6 basic emotions + neutral | Per-frame |
| Microexpressions | Onset/offset tracking | Per-frame |
| Engagement | 0–1 composite | Per-window |

## How it works

```
Video frames → MediaPipe 468-point landmarks → ROI extraction →
   rPPG signal → Bandpass filter → Spectral analysis → HR + HRV →
   Affect classifier → Emotion + microexpression labels
```

## Quality requirements

- Adequate lighting (no harsh backlight)
- Subject facing camera within ±30°
- Min 480p, 15+ fps
- SNR > 3.0 on the rPPG signal
- See [Quality Requirements](/multimodal/facial/quality-requirements)
