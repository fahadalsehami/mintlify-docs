---
title: "Quality Requirements"
description: "Conditions for reliable facial signal"
---


| Factor | Requirement |
| :--- | :--- |
| Resolution | ≥ 480p |
| Frame rate | ≥ 15 fps |
| Face angle | Within ±30° of camera |
| Lighting | Avoid harsh backlight, side-lit OK |
| Glasses | Anti-glare preferred; thick frames may block ROI |
| Mask | Blocks lower-face ROI; HR may still compute from forehead |
| rPPG SNR | > 3.0 required for HR/BP/HRV |

If quality requirements are not met, the engine returns `confidence: 0.0` and `requires_human_review: true`. It never returns fabricated values.
