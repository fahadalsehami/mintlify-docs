---
title: "Heart Rate Variability"
description: "SDNN, RMSSD, LF/HF, SD1, SD2"
---


HRV metrics from rPPG inter-beat intervals.

| Metric | Description |
| :--- | :--- |
| SDNN | Standard deviation of NN intervals |
| RMSSD | Root mean square of successive differences |
| LF/HF | Low-frequency / high-frequency ratio (sympathovagal balance) |
| SD1 | Poincaré plot short-term variability |
| SD2 | Poincaré plot long-term variability |

Min duration: 60 s. Lower SDNN and elevated LF/HF correlate with sympathetic dominance.
