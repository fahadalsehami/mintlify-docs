title: "Stress Index"
description: "0–100 stress score with PNS / SNS balance"
---


Computed by `_compute_stress_indices(hr, hrv_metrics)`.

| Field | Range |
| :--- | :--- |
| `stress_index` | 0–100 |
| `pns_index` | 0–100 (parasympathetic) |
| `sns_index` | 0–100 (sympathetic) |

PNS / SNS dominance is read from the LF/HF ratio and SDNN-band relationships.
