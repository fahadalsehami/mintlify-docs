---
title: "Spectral Features"
description: "MFCCs, centroid, bandwidth, rolloff, flatness"
---


| Feature | Description |
| :--- | :--- |
| MFCCs (13) | Mel-frequency cepstral coefficients |
| Spectral centroid | Center of mass of the spectrum |
| Spectral bandwidth | Spread around the centroid |
| Spectral rolloff | Frequency below which 85% of energy lies |
| Spectral flatness | Tonal vs noise-like character |

MFCCs power downstream classifiers (e.g. emotion, depression risk).
