---
title: "Prosodics"
description: "Speaking rate, articulation, pause patterns"
---


| Feature | Description |
| :--- | :--- |
| Speaking rate | Words per minute |
| Articulation rate | Syllables per second, excluding pauses |
| Pause patterns | Pause count, mean pause duration |

Slowed speaking rate and elongated pause patterns correlate with depressive psychomotor slowing.
