---
title: "Fundamental Frequency (F0)"
description: "Pitch features from speech"
---


F0 is extracted using a robust autocorrelation method with cepstral smoothing.

| Feature | Unit |
| :--- | :--- |
| F0 mean | Hz |
| F0 std | Hz |
| F0 min / max / range | Hz |

Reduced F0 range correlates with prosodic flatness — a documented marker in major depressive disorder.
