---
title: "Interim Results"
description: "Low-latency transcript previews during dictation"
--- Interim results stream sub-second previews so the editor can render text as the clinician speaks. Interim text is **not stable** — only the final result should be persisted. ```javascript
ws.on('interim', (e) => { // e.text is a preview; replace previous interim editor.setPreviewText(e.text);
}); ws.on('final', (e) => { // commit editor.commitText(e.text);
});
```
