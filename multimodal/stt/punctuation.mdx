---
title: "Punctuation"
description: "Smart punctuation for dictated text"
---


Smart punctuation infers sentence boundaries, commas, question marks, and quotation marks from prosody and syntax.

| Mode | Behavior |
| :--- | :--- |
| `off` | No punctuation inserted |
| `basic` | Sentence-ending punctuation only |
| `smart` | Default — full inference including commas and quotes |

Smart punctuation has known interaction with editors that auto-capitalize. See [Smart Punctuation Integration](/multimodal/stt/best-practices-transcribe).
