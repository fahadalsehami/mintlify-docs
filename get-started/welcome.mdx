Medera is the AI infrastructure platform for behavioral and mental health. It combines **multimodal clinical sensing**, **purpose-built medical LLMs**, and an **agentic framework** of 24 composable clinical agents — delivered through a single API and a HIPAA-grade runtime that drops into existing EHR and payer workflows.

<Tip>
  Medera's goal is to be the most accurate, defensible, and clinician-ready **AI platform for behavioral and mental health teams** — without compromises on integration speed, evidence, or regulatory compliance.
</Tip>

## Why Medera

|                                       |                                                                                                                                                                                  |
| :------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Purpose-built for behavioral health** | Validated screeners (PHQ-9, GAD-7, AUDIT-C, C-SSRS), RDoC construct mapping, and 42 CFR Part 2 controls are first-class — not bolted on.                                       |
| **Multimodal by default**             | Voice (Whisper, Deepgram nova-2-medical), facial physiology (HR, BP, HRV, respiration, stress), and linguistic content fuse into one clinical signal.                            |
| **Composable clinical agents**        | 24 production agents with a documented expert registry, A2A protocol, and an Agent Builder Canvas with 16 node types.                                                            |
| **Evidence-anchored**                 | Every clinical claim is anchored to a quoted span, a screener score, or a peer-reviewed citation. Confidence is calibrated, never invented.                                      |
| **Enterprise-grade runtime**          | PostgreSQL with Row-Level Security on 100+ tables, AES-256-GCM PHI encryption, Merkle-tree audit integrity, and HIPAA + 42 CFR Part 2 controls baked into the request path.      |

## Bringing it All Together

This documentation site explains how to use the Medera API and provides example workflows.

- Each component of the Medera platform has its own tab for detailed documentation: [Multimodal Sensing](/multimodal/overview), [Text Generation](/textgen/overview), [Agentic Framework](/agentic/overview), and [Coding](/coding/overview).
- The [API Reference](/api-reference/welcome) tab provides detailed specifications for each available endpoint.
- The [Console](https://app.medera.ai) is where you create an account and client credentials to begin your journey.
- The Quickstarts at the top of the Home tab outline how to get started fast. Start with [Authentication](/authentication/overview).
- The [SDKs section](/sdks/overview) covers the official [JavaScript SDK](/sdks/js/overview), [Python SDK](/sdks/python/overview), [Dictation Web Component](/sdks/dictation-component), and [Postman collection](/sdks/postman).
- The [Examples Repository](https://github.com/medera-ai/examples) provides working code for authentication, streaming, text generation, proxy setups, and more.
- The [Release Notes](/release-notes/overview) page provides information about the API change policy, scheduled upcoming changes, and links to release notes per product.
