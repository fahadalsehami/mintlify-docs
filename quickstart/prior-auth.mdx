---
title: "Quickstart — Prior Authorization"
description: "Generate evidence-based PA letters"
---


Generate a prior authorization letter from chart, payer policy, and peer-reviewed evidence.

```bash
curl -X POST https://api.medera.ai/api/pa/initiate \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "patient_id": "pat_abc",
    "service_codes": ["90834", "H0036"],
    "payer_id": "payer_aetna_commercial",
    "clinical_facts": { "from_chart": true },
    "evidence_base": ["pubmed", "internal_protocols"]
  }'
```

Returns a `pa_id` and triggers the PA workflow:

```
PA_INITIATED → PA_CRITERIA_EVALUATION → PA_CRITERIA_EVALUATED →
PA_DOCUMENTS_READY → PA_SUBMITTED → PA_IN_REVIEW →
PA_APPROVED | PA_DENIED → (PA_APPEAL | PA_P2P)
```

See [Prior Authorization Agent](/agentic/agents/prior-authorization).
