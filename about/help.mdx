## Support channels

| Channel | When to use |
| :--- | :--- |
| [help.medera.ai](https://help.medera.ai) | General product questions, ticket history |
| [status.medera.ai](https://status.medera.ai) | Incidents, scheduled maintenance |
| [security@medera.ai](mailto:security@medera.ai) | Vulnerability disclosure |
| [compliance@medera.ai](mailto:compliance@medera.ai) | BAA, DPA, audit requests |
