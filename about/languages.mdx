Medera ships a **BH-tuned speech engine** (Speech-to-Behavioral-Text) and a **language-agnostic vocal-acoustic engine**. Language support varies by surface — the matrices below show what's GA, what's in private beta, and what's on the roadmap.

<Note>
The vocal-acoustic engine — F0, jitter, shimmer, HNR, prosodic flatness, depression / anxiety / distress indices — is **language-agnostic** and ships unchanged across every locale. The same is true for the facial physiological engine and the neurobehavioral construct computer.
</Note>

## Translation policy

Patient-facing translations preserve clinical fidelity.

**Validated screeners use the published validated translation** (Spitzer et al. for PHQ-9, Sawaya et al. for the Arabic validation) — never a model-generated one.

## Output language

Even when the input language is non-English, **structured emission stays in clinical English** — DSM-5-TR labels, ICD-10 codes, C-SSRS bands, instrument names — so the data slots directly into your EHR.

This is configurable: set `output_language: "source"` to emit labels in the source language.
