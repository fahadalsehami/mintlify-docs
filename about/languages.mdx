---
title: "Languages"
description: "Language support across Medera APIs"
---


Medera supports the following languages across speech-to-text, text generation, and patient-facing agents. Language support varies by surface — check the table below.

| Language | STT | Text Gen | Patient-facing | Validated screeners |
| :--- | :--- | :--- | :--- | :--- |
| English (US) | ✓ | ✓ | ✓ | PHQ-9, GAD-7, AUDIT-C, C-SSRS |
| English (UK) | ✓ | ✓ | ✓ | PHQ-9, GAD-7 |
| Spanish (US) | ✓ | ✓ | ✓ | PHQ-9, GAD-7 |
| Spanish (LATAM) | ✓ | ✓ | ✓ | PHQ-9, GAD-7 |
| Arabic (MSA) | ✓ | ✓ | ✓ | PHQ-9, GAD-7 |
| French (FR) | ✓ | ✓ | ✓ | PHQ-9 |
| German (DE) | ✓ | ✓ | ✓ | PHQ-9 |
| Portuguese (BR) | ✓ | ✓ | ✓ | PHQ-9 |
| Mandarin (Simplified) | ✓ | ✓ | beta | — |
| Vietnamese | ✓ | beta | beta | — |
| Tagalog | ✓ | beta | beta | — |

Patient-facing translations preserve clinical fidelity — validated screeners use the published validated translation, never a model-generated one.
