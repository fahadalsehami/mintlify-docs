---
title: "Standard Templates"
description: "Out-of-the-box templates"
---

Default templates available via `GET /api/therapy/templates`:

| Template key | Purpose |
| :--- | :--- |
| `soap_outpatient_bh` | BH outpatient SOAP |
| `soap_psychotherapy_v3` | Psychotherapy session note |
| `referral_specialty_v2` | Specialty referral letter |
| `discharge_summary_v3` | Discharge summary |
| `crisis_documentation_v1` | Crisis event documentation |
